# 💧 Розрахунок одноступеневої та двоступеневої установки зворотного осмосу (Streamlit)

Цей веб-додаток створено на основі математичної моделі з Google Colab блокнота **`RO-2022.ipynb`**. Він дозволяє моделювати стаціонарні режими роботи мембранних установок зворотного осмосу (ЗОУ) для водоочищення та знесолення води.

---

## 📌 Основні можливості

1. **Одноступенева схема (ЗО-1):**
   - Моделювання мембранного модуля з рециркуляцією частини концентрату.
   - Ітераційний розрахунок рівноважних концентрацій ($C_v$, $C_p$, $C_k$) та витрат потоків ($G_i$, $G_p$, $G_k$, $G_r$, $G_s$).
   - Повна автоматична перевірка водного та сольового матеріального балансу (**BBB Test** з Colab: $LP = RP$).
   - Інтерактивна діаграма потоків Санкі (Sankey Diagram).

2. **Двоступенева схема (ЗОУ-2):**
   - Двоступеневе знесолення за пермеатом (пермеат 1-го ступеня живить 2-й ступінь).
   - Об'єднання рециркулятів обох ступенів у змішувачі `zmish2`.
   - Контроль та автопідбір коефіцієнта $X_{r2}$ для забезпечення проектної умови $C_v \approx C_i$.
   - Розрахунок ступеня очищення та виходу надчистого пермеату.

3. **Параметричний аналіз & графіки:**
   - Дослідження залежностей $C_p$, $C_k$, $G_i$, $G_s$ від коефіцієнта рециркуляції $X_r$.
   - Вплив навантаження $X_p$ та селективності $X_z$.

4. **Експорт даних:**
   - Завантаження розрахункових таблиць потоків у форматі CSV (Excel).

## 🚀 Як запустити локально на комп'ютері

### Крок 1. Перевірка Python
Переконайтеся, що на вашому комп'ютері встановлено **Python** (версії 3.9 – 3.12).
> ⚠️ Під час встановлення Python обов'язково поставте прапорець **"Add Python to PATH"**.

### Крок 2. Встановлення бібліотек
Відкрийте термінал (PowerShell або Командний рядок) у цій папці (`13, 14`) і виконайте:
```bash
pip install -r requirements.txt
```

### Крок 3. Запуск веб-додатка
Виконайте команду:
```bash
streamlit run app.py
```
Або просто двічі клікніть файл **`run_app.bat`**.

Після цього у вашому веб-браузері відкриється сторінка додатку (зазвичай за адресою `http://localhost:8501`).

## 📐 Структура проекту

- `app.py` — головний файл веб-додатка на Streamlit (інтерфейс, візуалізації, віджети).
- `ro_model.py` — математичне ядро з функціями `zmishyvach`, `rozdiluvach`, `membrana`, `zmish2`, чисельними розрахунками та балансами.
- `requirements.txt` — перелік необхідних бібліотек Python.
- `run_app.bat` — скрипт для швидкого запуску в один клік на Windows.
